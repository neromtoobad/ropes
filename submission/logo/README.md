# ROPES — logo pack

Brand colours: mark `#00e58a` (the same green as UP in the game) on `#0b0a13`.
Display face is Russo One, matching the product.

| File | Use |
|---|---|
| `ropes-logo-1024.png` | **Primary.** Square, brand background — the one to submit. |
| `ropes-logo-1024-transparent.png` | Square, transparent — for light or custom backgrounds. |
| `ropes-logo-512.png` | Smaller square, for avatars and favicons. |
| `ropes-wordmark-dark.png` | Mark + ROPES, 1600×500 — headers, banners, slide footers. |
| `ropes-wordmark-transparent.png` | Same, transparent. |
| `ropes-mark-full-1024.png` | The illustrated rope-and-candle mark, square. |
| `ropes-mark-full-transparent.png` | Same, transparent, 1600px tall. |

Two marks on purpose: the simplified knot is the logo (it stays legible down to
16px), and the illustrated rope-and-candle is the hero artwork used on the
landing page — a knot whose centre is a candlestick body.

Note: the illustrated mark carries a dark outline and glow from its original
artwork, so it sits best on a dark background. Use the simplified knot on light.
